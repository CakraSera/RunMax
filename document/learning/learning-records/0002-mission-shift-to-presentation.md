# Mission shifted to presenting the project

The learner's goal changed from "debug tracing like console.log" to "present the RunMax agent project, explained like to a 7-year-old." Tracing debug is kept as a supporting skill because the demo shows Langfuse traces. Lessons should now teach the product story (agents, tools, workflow, safety rules, evals) with kid analogies plus the real terms, and produce presenter-ready artifacts (cheat sheets, demo scripts).
