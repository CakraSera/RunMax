# Mission: Present the RunMax agent

## Why
You must stand up and present this project (Weeksmith, the running-week agent). You want to explain it so simply that anyone follows — "like teaching a 7-year-old" — and still survive questions about tools, MCP, evals, and tracing.

## Success looks like
- You can tell the agent's story in 5 sentences without notes.
- You can run one live demo (runner:dev or studio) and say what each step proves.
- You can answer "why one hard day?", "what is MCP?", "what is Langfuse?" in one breath each.

## Constraints
- Kid-simple language first, real terms alongside (diary = Log, camera = Langfuse).
- Everything grounded in this repo; no invented numbers.
- Short lessons, one win each.

## Supporting skill (kept from earlier mission)
- Debug tracing like console.log: print the `traceId`, look it up. Needed if the live demo hits Langfuse.

## Out of scope
- OpenTelemetry internals beyond "the camera ships in the background".
- Changing the product (new tools, new agents).
